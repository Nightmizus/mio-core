# Security

Please do not open a public issue for a vulnerability that could expose private chats,
uploaded media, API keys, session tokens, or the Music Mizu Deploy Key.

Report security issues privately through GitHub Security Advisories for this repository.
Include the affected version, reproduction steps, expected impact, and any suggested
mitigation. Do not include real credentials or private music files in the report.

The supported release is the latest commit on `main`. Rotate `MIO_LLM_API_KEY`, the
session secret, and the repository Deploy Key immediately if any of them may have leaked.
